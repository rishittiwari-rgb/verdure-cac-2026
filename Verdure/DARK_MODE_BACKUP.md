# Dark Mode Backup — "Deep Evergreen" (v1)

The original deep-evergreen dark palette, saved so it can be restored at any time.
To revert: paste these dark hex values back into the matching `Color.adaptive(light, DARK)`
calls in `Verdure/Verdure/Theme/VerdureTheme.swift` (replace only the second / dark arg).
