# Idealist Listings API inquiry draft

Official entry: [Idealist Open Network API inquiry](https://www.idealist.org/en/open-network-api).
This is an external partnership request, not an API key or a production
integration. The [Listings API documentation](https://api-sandbox.idealist.org/listings-api)
requires approved access and attribution.

## Missing form identity

- Verdure organization or legal entity name
- Contact person's name
- Business email address
- Preferred website/domain: `verdure-app.com` (confirmed canonical)

## Proposed inquiry text

> Verdure is an iOS app for discovering public local events and volunteer
> opportunities, initially focused on San José and the South Bay. We want to
> display current, geographically relevant volunteer listings from Idealist's
> Listings API inside our free Opportunities discovery flow, with clear
> Idealist attribution and a link to the operating organization. Verdure will
> not take applications, collect résumés or present a job-board workflow.
> Our audience includes students and families, so we need eligibility and
> minimum-age fields where available. Could you share access requirements,
> attribution and caching terms, pricing, and the recommended way to filter
> by location and age eligibility?

Do not submit with guessed contact details. If the form includes commercial
terms or an agreement, capture it for owner review before accepting it.
